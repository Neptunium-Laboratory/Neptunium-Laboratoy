About the lab

Neptunium Laboratory is a small, independent studio building apps, software, and websites. Everything we release is open source — the code is the product, and anyone is free to read it, learn from it, or build on top of it.

Openly built

Source code, design decisions, and progress are visible from day one, not published after the fact.

Independently run

No investors dictating the roadmap — just a small team building things worth using.

Made to be reused

Every project is licensed so other developers can fork it, adapt it, and ship their own version.

Nothing in the lab is locked away. If we build it, you can read it, fork it, and run it yourself. — The Neptunium Laboratory philosophy

Privacy policy

Last updated September 2026.

What this site collects

This website does not use tracking cookies, analytics scripts, or advertising pixels. We don't collect names, email addresses, or any other personal information just from you visiting this page.

Our products

Neptunium Laboratory's apps and software are still in development. Each one will publish its own privacy policy before release, describing exactly what it collects, if anything, and why. As a rule, we collect the minimum needed for a product to work, and nothing more.

Open source, open to audit

Because our code is open source, you don't have to take our word for any of this. Every repository is public on GitHub, so you — or anyone else — can read exactly how a project handles data before deciding to use it.

Changes to this policy

If this policy changes, we'll update the date at the top of this page. Continued use of our sites and software after a change means you accept the update.

Contact

Questions about this policy or how a specific project handles data can be raised as an issue on our GitHub.
